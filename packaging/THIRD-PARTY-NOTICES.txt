YT-Downloader.exe — third-party software

The app itself is MIT-licensed (see LICENSE in the source repository,
https://github.com/lifeupnorth/YouTubeDownloader). The one-file .exe also
contains the following programs and libraries, each under its own license.
This file is an overview; the full license texts are in
THIRD-PARTY-LICENSES.txt (everything except ffmpeg and deno), FFMPEG-LICENSE.txt
and DENO-LICENSE.txt, all next to this file and inside the .exe.

ffmpeg
  The "essentials" build by gyan.dev (version 9.0.2), used to merge video and
  audio and to convert audio. It's licensed under the GNU General Public
  License version 3 (GPLv3); the full license is in FFMPEG-LICENSE.txt.
  ffmpeg 9.0.2's source: https://ffmpeg.org/releases/ffmpeg-9.0.2.tar.xz
  The build, the libraries it includes and their sources:
  https://www.gyan.dev/ffmpeg/builds/ and
  https://github.com/GyanD/codexffmpeg/releases/tag/9.0.2
  ffmpeg is a separate program that the app runs; it isn't linked into the app.

deno
  The official Windows build of deno (https://deno.com/), the JavaScript
  runtime yt-dlp uses for YouTube. MIT license; the full license is in
  DENO-LICENSE.txt next to this file. Source: https://github.com/denoland/deno
  deno is a separate program that yt-dlp runs; it isn't linked into the app.

yt-dlp
  https://github.com/yt-dlp/yt-dlp
  Released into the public domain (The Unlicense).

yt-dlp-ejs
  https://github.com/yt-dlp/ejs
  The script deno runs to solve YouTube's JavaScript challenges. Released
  into the public domain (The Unlicense); it includes astring (MIT license)
  and meriyah (ISC license).

Qt and PySide6 (Qt for Python)
  The window is built with Qt 6.12 through PySide6 6.12 (its "Essentials"
  package, with shiboken6), https://www.qt.io/qt-for-python. They're used
  under the GNU Lesser General Public License version 3 (LGPLv3); its text,
  and the GPLv3 text it builds on, are in THIRD-PARTY-LICENSES.txt.
  Sources: https://code.qt.io/cgit/pyside/pyside-setup.git (PySide6 and
  shiboken6) and https://code.qt.io (Qt), or https://download.qt.io.
  Qt includes third-party code (FreeType, HarfBuzz, PCRE2, zlib, libpng,
  libjpeg and others) under their own licenses, listed at
  https://doc.qt.io/qt-6/licenses-used-in-qt.html.
  The Qt and PySide6 libraries aren't modified. The LGPL lets you use the
  app with your own build of them: the app's source and the script that
  builds the .exe (packaging/build_exe.py) are in the source repository, so
  the .exe can be rebuilt with another Qt or PySide6.
